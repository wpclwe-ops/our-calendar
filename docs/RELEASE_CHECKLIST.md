# Проверка размещённой версии

Это ручные приёмочные действия после настройки секретов. В этой среде они ещё не выполнялись на реальных аккаунтах.

- [ ] Приватный репозиторий создан, основной код закоммичен, CI зелёный.
- [ ] `DEMO_MODE=false`, TLS работает, `/data` постоянный, одна реплика, сервер не засыпает.
- [ ] `/health` возвращает свежий heartbeat, мониторинг настроен.
- [ ] BotFather Main Mini App и menu URL совпадают с PUBLIC_URL; webhook проверен.
- [ ] Первый человек Start → создать → пригласить; второй Start → открыть ссылку.
- [ ] Третий аккаунт не входит, даже зная event ID; повторное приглашение не работает.
- [ ] Попытка второго и третьего принять ссылку одновременно даёт только одно второе место.
- [ ] Создание и изменение события видно обоим; отправлено только одно уведомление второму на его языке.
- [ ] Партнёры в разных зонах видят одинаковый момент; «Весь день» остаётся на одной дате.
- [ ] Повторение проходит DST, один статус и одно исключение не меняют соседние экземпляры.
- [ ] Напоминания приходят при закрытом Mini App; перенос отменяет старое расписание; прошлые точки не догоняются.
- [ ] Корзина и восстановление работают для события и экземпляра; окончательно удалённый экземпляр не возвращается в серии.
- [ ] Выход сразу закрывает API; возврат возможен тому же аккаунту, замены нет.
- [ ] ZIP скачивается, изменённый архив отклоняется; diff не применяет поля без выбора.
- [ ] ICS импортирован в целевые календарные приложения; локальное время серии сохраняется.
- [ ] Полное удаление просит двоих; в ожидании виден только countdown; любой может отменить.
- [ ] На отдельном тестовом стенде после очистки архив возвращает только исходную пару и после двух согласий.
- [ ] После такого восстановления каждый отдельно включает свои напоминания.
- [ ] База и signing keys восстановлены на отдельном стенде из служебной резервной копии.

Завершение этих проверок относится к ядру 0.2.0. Полный релиз по ТЗ дополнительно требует реализации всех оставшихся пунктов IMPLEMENTATION.md.
